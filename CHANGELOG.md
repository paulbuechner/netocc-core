Each release's section becomes its GitHub release notes and the packages' release notes (`python build.py changelog --version <x.y.z>`).

## [Unreleased]

### Added

- C# bindings for 30 OCCT 8.0.1 packages, generated by netocc-generator, in the pythonocc layout (`OCC.Core.<Package>`, OCCT names unchanged):
  - foundation: Standard, gp, Quantity;
  - topology and geometry: TopAbs, TopLoc, TopoDS, TopTools, TopExp, Poly, Geom, BRep;
  - properties: GProp, BRepGProp;
  - modeling: BRepBuilderAPI, BRepPrimAPI, BRepAlgoAPI, BRepMesh;
  - STEP: IFSelect, XSControl, STEPControl;
  - OCAF: TDF, TNaming, PCDM, TDataStd, TDocStd, BinDrivers, XmlDrivers;
  - XCAF: XCAFDoc, XCAFApp, STEPCAFControl.
- Handles map to proxy objects (`Handle(T)` ⇄ `T`, `T.DownCast`), and value types (`gp_Pnt`, `gp_Trsf`, `Poly_Triangle`, `Quantity_Color`, ...) are C# structs with OCCT's memory layout.
- C++ references are `ref` parameters, enum references included.
- Strings: `TCollection_AsciiString` is UTF-8 and `TCollection_ExtendedString` UTF-16; `Standard_GUID` maps to `System.Guid`.
- OCCT exceptions surface as `OcctException`.
- OCAF documents stay valid while any label, attribute or `TNaming_Builder` proxy lives.
- One AnyCPU assembly for .NET Framework 3.5 to 4.8, .NET 6, 8 and 10, and netstandard2.0.
- Natives for win-x64, win-x86, linux-x64 and osx-arm64, one package each (`NetOcc.runtime.<rid>`).
