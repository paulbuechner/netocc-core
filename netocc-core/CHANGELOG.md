# Changelog

Notable changes to the NetOcc packages (`NetOcc`, `NetOcc.runtime.<rid>`). Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow [Semantic Versioning](https://semver.org/). Each release's section becomes its GitHub release notes and the packages' release notes (`python build.py changelog --version <x.y.z>`).

## [Unreleased]

### Added

- C# bindings for OCCT 8.0.1, generated by netocc-generator, one namespace per OCCT package (`OCC.Core.<Package>`), OCCT names unchanged: all 362 packages of the FoundationClasses, ModelingData, ModelingAlgorithms, ApplicationFramework and DataExchange modules and of Visualization's TKService, TKV3d, TKOpenGl and TKMeshVS:
  - geometry, topology and modeling algorithms (booleans, fillets, offsets, sweeps, shape healing, meshing, HLR);
  - OCAF and XCAF documents;
  - STEP, IGES, STL, glTF, OBJ, PLY and VRML;
  - visualization: `AIS`, `V3d`, `Graphic3d`, `Prs3d`, `StdPrs`, `SelectMgr`, `MeshVS`, `Font`, `Image` and the OpenGL driver. `Aspect_Window.FromNativeHandle(handle, display)` wraps a native window (an HWND, an X11 window, an NSView) for `V3d_View.SetWindow`.

  Members that don't map to C# yet are left out.
- Handles map to proxy objects (`Handle(T)` ⇄ `T`, `T.DownCast`). A `Handle(T)&` is a `ref T` that keeps its proxy unless OCCT puts another object there, also when the call throws or an argument fails its check.
- NCollection arrays, lists and sequences are C# classes named by OCCT's aliases (`TColgp_Array1OfPnt`, `TopTools_ListOfShape`, `TColStd_HArray1OfReal`), including `TColgp`, `TColGeom` and `TColGeom2d`, which OCCT 8 dropped as packages:
  - indexers with OCCT's bounds (sequences from 1), `IEnumerable<T>` and `Count`;
  - arrays of numbers and value types copy to and from C# arrays in one step (`new TColgp_Array1OfPnt(points)`, `ToArray()`);
  - the handle-managed variants (`TColgp_HArray1OfPnt`) are subclasses of their collection that pass as handles;
  - maps too (`TopTools_IndexedMapOfShape`, `TopTools_DataMapOfShapeListOfShape`), with indexers by key or number and `KeyValuePair` enumeration.
- `math_Vector` and `math_IntegerVector` with indexers, bulk copies and arithmetic operators.
- OCCT 8's vectors (`NCollection_LinearVector`, `NCollection_DynamicArray`) and open-addressing maps (`NCollection_FlatMap`, `NCollection_FlatDataMap`) as collections; a collection OCCT names no alias for is named after its arguments (`NCollection_Array1_BRepGraph_NodeId`, `OCC.Core.NCollection.NCollection_DynamicArray_int`).
- Other class template instances are classes too, named by an OCCT alias (`IntPolyh_ArrayOfPoints`) or after their arguments (`BRepGraph_MutGuard_BRepGraphInc_VertexDef`). Move-only ones return by value (`using var guard = editor.Mut(vertex)`).
- OCCT 8's range-for iterators are `IEnumerable<T>`: `foreach (var face in new TopExp_Explorer(shape, TopAbs_FACE))`.
- Value types are C# structs with OCCT's memory layout: all of `gp` (points, vectors, axes, transformations, lines, circles, planes, quadrics, ...), `Bnd_Box`, `Bnd_Box2d`, `Quantity_Color`, `Quantity_ColorRGBA` and `Poly_Triangle`. Their methods run OCCT's code (trivial math is managed), and OCCT's `+ - * / ^` are C# operators; `gp` itself is a static class (`gp.Origin()`).
- Nested and namespace types have flat names (`Geom_Curve::ResD1` is `Geom_Curve_ResD1`, `gp_Dir::D` is `gp_Dir_D`). Plain data, such as OCCT 8's evaluation results, is a C# struct with public fields (`curve.EvalD1(u).Point`); enums keep their C++ underlying type.
- OCCT 8's `BRepGraph`: typed ids are structs (`BRepGraph_FaceId`, `id.Index`), and the node iterators are classes (`new BRepGraph_FaceIterator(graph)`).
- C++ references are `ref` parameters, enum references included.
- Raw pointers: a class pointer is its proxy (`null` for `nullptr`; a returned one borrows from its owner, a transient's owns a reference), `T*&` a `ref` of the proxy. Pointers to numbers and structs are C# arrays pinned for the call (`MathUtils.SortRoots(roots, n)`, `obb.GetVertex(corners)`); `void*`, function pointers and pointers a constructor or setter keeps are `IntPtr`. `Standard_ExtString` is a UTF-16 `string`, `const char*&` a `ref string`, and a `Standard_OStream*` a lent stream.
- What an object keeps a reference to stays alive with it, so no `GC.KeepAlive` is needed:
  - constructor arguments: `new BRepGraph_FaceIterator(graph)`, a boolean's shared `BOPAlgo_PaveFiller`, adaptor tools and their curves, VRML nodes and their scene;
  - member arguments: `extrema.Initialize(surface, ...)`, until the next call replaces them;
  - the object a returned guard or iterator points into: `editor.Mut(vertex)` keeps the graph.

  What a constructor keeps, and the object behind a returned guard, outlive the finalizer too: a guard dropped without `Dispose` is safe.
- All of BRepMesh, with its triangulation data structures (`BRepMesh_Triangle`, `BRepMesh_DataStructureOfDelaun`): a C array by reference (`int (&)[3]`) is a C# array of that length.
- `ShapeProcess.ToOperationFlag(name, ref known)` maps an operation name to its flag.
- `char32_t` is a `uint` (a UTF-32 code point), and a member's `size_t&` return a `ref UIntPtr`. A `size_t` is a `ulong`: on x86 a value above 32 bits throws `OcctException` (`Standard_OutOfRange`), as for C `long`.
- `char` is its `byte`, by value too (`TCollection_HAsciiString.Value(1)`): its bits, not a character through a code page.
- References of every fixed-width integer, `char` (its byte), `size_t`, C `long` (a C# `long`, range-checked where `long` is 32-bit) and `Standard_GUID` (`ref Guid`) are `ref` parameters, and a transient passed by `T&` is its proxy; byte-sized ref returns write through (`color.x() = 200`).
- A C++ call only one overload takes is wrapped even where other arities are ambiguous (`new IntPolyh_ArrayOfPoints()`), and a transient OCCT returns by value comes back as a proxy that owns it (`BRepGraph_Tool_Edge.CurveAdaptor(graph, edge)`).
- Standard library types: `std::string`, `std::string_view` and string streams are strings; `std::array` is a C# array (`box.Center()`), `std::optional` a nullable (`range.Min()`), `std::bitset` a `ulong` mask (shape-processing flags), `std::pair` a class with `First` and `Second`, `std::complex<double>` an `OCC.Core.Complex`.
- Strings: `TCollection_AsciiString` is UTF-8 and `TCollection_ExtendedString` UTF-16; `Standard_GUID` maps to `System.Guid`.
- C++ streams are `System.IO.Stream` parameters (`BRepTools.Write(shape, stream)`, `DumpJson`), lent for the call; readers leave a seekable stream where they stopped.
- Classes without declared constructors can be created (`new BRep_Builder()`).
- References a member returns write through: numbers, enums and structs as C# `ref` returns (`fix.FixReorderMode() = 1`), classes and collections as proxies that borrow the object and keep its owner alive (`block.ChangeShapes().Append(shape)`). Members that return their own object for chaining return `void`.
- What OCCT deprecates is wrapped and `[Obsolete]`, so C# callers get the compiler warning C++ callers get (`Geom_BSplineCurve.Poles(array)`, `Message_ProgressSentry`).
- Overloads C# can't tell apart reach the most capable one: `ref` returns (`matrix.Value(1, 2) = 5.0`) and UTF-16 strings (`new TCollection_HExtendedString(text)` keeps non-ASCII text). OCCT's `GetType()` (curve and surface types) hides `object.GetType()`.
- OCCT exceptions surface as `OcctException`; `e.Is<Standard_DomainError>()` tells whether OCCT raised that class or a subclass. The exception classes themselves are classes (`Standard_OutOfRange`).
- OCAF documents stay valid while any label, attribute or `TNaming_Builder` proxy lives.
- One AnyCPU assembly for .NET Framework 3.5 to 4.8, .NET 6, 8 and 10, and netstandard2.0.
- Natives for win-x64, win-x86, linux-x64 and osx-arm64, one package each (`NetOcc.runtime.<rid>`).
